# PLAN.md — Teman Belajar ASD

## 1. Project Overview

**Teman Belajar ASD** is a web-based learning application for **Algoritma dan Struktur Data (ASD)** that uses a **Large Language Model (LLM)**  and **guided learning**.

The system helps students learn ASD concepts through a structured flow:

1. Concept explanation
2. Code example / implementation example
3. Exercise
4. Feedback / discussion
5. Summary
6. Progress tracking

The main goal is to help students understand ASD gradually, reduce misconceptions, and keep generated content aligned with official course materials.
Materials:
- Pengantar
- ADT Sederhana
- List
- Mesin Karakter/Kata
- Stack & Queue
- Set & Map
- List Linier
- Binary Tree
- Aplikasi
---

## 2. Problem Scope

Students often struggle with ASD because the material is abstract, dynamic, and requires strong reasoning skills. Common problems include:

- Difficulty understanding abstract concepts such as pointers, nodes, trees, and graphs
- Difficulty following dynamic changes in data structures
- High cognitive load because students must understand concepts, algorithm flow, and implementation at the same time
- Misconceptions in basic concepts that affect advanced topics
- Static learning materials that do not adapt to student needs
- General-purpose LLM chatbots may produce answers that are not aligned with the curriculum

This system focuses on solving those issues by combining structured learning flow, official course material retrieval, and controlled LLM generation.

---

## 3. Goals

The system should:

- Provide a structured ASD learning path using guided learning
- Generate explanations, examples, exercises, feedback, and summaries using an LLM
- Help students identify and correct misconceptions
- Store and show student learning progress
- Provide a simple, intuitive, and responsive learning interface

---

## 4. User

### Primary Actor

**Student / Mahasiswa**

The student uses the system to:

- Log in
- Choose an ASD topic
- Learn the material step by step
- View code examples
- Answer exercises
- Receive feedback
- View summaries
- Track learning progress

## 5. Core Features

| ID | Feature | Description |
|---|---|---|
| FT-01 | Login | User logs in using email and password |
| FT-02 | Logout | User ends the active session |
| FT-03 | Choose ASD Topic | User selects a topic such as array, linked list, stack, queue, tree, graph, searching, or sorting |
| FT-04 | Show Material | System displays structured concept explanation generated by LLM |
| FT-05 | Show Example | System displays code example or step-by-step implementation explanation |
| FT-06 | Exercise | System provides practice questions based on the selected topic |
| FT-07 | Exercise Discussion | System provides explanation after the user submits an answer |
| FT-08 | Material Summary | System summarizes the learned topic at the end of the session |
| FT-09 | Learning Progress | System displays completed topics, ongoing topics, scores, and progress percentage |
| FT-10 | LLM Content Generation | System generates material, examples, exercises, and feedback dynamically |
| FT-11 | Guided Learning Flow | System forces a structured flow: material → example → exercise → summary |
| FT-12 | Answer Feedback | System gives feedback based on user answers |
| FT-13 | Adaptive Learning Engine | System analyzes user weaknesses based on exercise performance |
| FT-14 | Adaptive Content | System adjusts content difficulty based on user performance |
